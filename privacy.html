Privacy Policy

Last updated: November 11, 2026

Night Shift Studio is a private publishing tool used only by the owner of the YouTube channel "Night Shift — Work With Me". It is not offered to the public.

What the app accesses

With the channel owner's consent, the app uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, set thumbnails, titles, descriptions, playlists and comments, manage the channel's live stream, and read the channel's own statistics.

What the app stores

The app stores an OAuth access/refresh token for the owner's account on the owner's private server. It does not collect, sell or share personal data of any other person. Channel statistics are used only to plan the channel's own videos.

Third parties

Data is exchanged only with Google/YouTube APIs. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: via the contact options on the channel's About page.
